# Validate encodings
Validate an encoding in MEI or TEI against the schema given in the file.


List of (prov) activities:


Converting
Derivative Generating: Automated conversion of the source notation type to other lute notation types
Luteconv Converting: Fronimo files are converted to MEI using luteconv
Abtab notehead Converting: Tablature to notehead transcription

Editing
Musescore Editing: Sources are transcribed and edited in CMN in Musescore
CMN Editing: Correction of the abtab polyphonic transcription

Transcribing
Abtab polyphonic Transcribing: Tablature to polyhonic transcription

Proofreading
MEI Proofreading: Proofreading of the MEI Files

Typesetting
Fronimo Typesetting: Sources are typeset in Fronimo


Validating:
XML Validating: Validating XML structure
Schematron Validating: Checking file against MEI and TEI schema
Header Validating: Checking Header metadata agains graph


Metadata Provision:
Prov Data Provision: Generating Provenance Graph data
Metadata Provision: Generating Metadata for bibliographic database

Provision:
RDM Provision: Provide MEI data for release on TUW RDM
Platform Provision: Provide MEI data for release on E-Laute Platform
